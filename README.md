## Join the workspace

Once you have collaborator access:

```sh
git clone https://github.com/Josh-Roe/SuperhumanGo_HackProj.git
cd SuperhumanGo_HackProj
```

Create a task and a branch before starting work. Keep `main` ready for the team demo and coordinate overlapping files in the task discussion.

Application setup and run instructions will be added after the team chooses the project and stack. No application code or dependencies have been added.
