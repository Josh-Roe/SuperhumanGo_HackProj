# Hackathon brief

Sources: [event overview](https://mtc-x-grammarly.devpost.com/) and [rules](https://mtc-x-grammarly.devpost.com/rules), read October 16, 2026.

## Objective

Build a working prototype with **Superhuman Go or Grammarly agents as a central part of the experience**. Other tools, APIs, and frameworks may be combined with them. The demo should show the core functionality and make the agent's contribution clear.

Choose one primary track:

| Track | Focus |
| --- | --- |
| Productivity | Automate repetitive tasks or improve a workflow |
| Inclusion & Accessibility | Reduce barriers to communication, learning, work, or information |
| Wildcard | Explore a creative or unexpected use of agents |

The team has not selected an idea or track yet.

## Submission requirements

- [ ] Project name and selected primary track
- [ ] Description of the problem, intended users, and solution
- [ ] Explanation of the Superhuman Go or Grammarly agent integration
- [ ] Short video demonstrating core functionality
- [ ] Source repository link and a working demo link if available
- [ ] Setup instructions that let judges review the project
- [ ] All contributing team members listed
- [ ] Technologies, tools, and credits, including disclosure of pre-existing code, templates, or assets
- [ ] Submitted links accessible to judges, without credentials or private data

Finalists should be ready for a **2-minute live pitch and demo**. This setup does not submit anything to Devpost.

## Judging criteria

Impact and usefulness, agent integration, technical execution, creativity and innovation, and user experience. No weighting is published in the overview.
